# Rutz's Discord Table

디스코드에서 말하면 그 사람의 초상화가 빛납니다. 시스템을 가리지 않는 파티 초상화와 채팅 도구입니다.

- **디스코드 음성 연동** — 말하는 사람 강조, 자리비움 표시(말하거나 키를 누르면 자동 해제)
- **파티 초상화** — HP·SAN 막대, 채팅 말풍선, `@표정`
- **귓속말·공유 노트 창**, 채팅 묶기·입력 중 표시·글꼴
- D&D 5e · Call of Cthulhu 7e · PF2e · 인세인 지원, 그 밖의 시스템은 토큰 막대를 그대로 씁니다.

설정은 *모듈 설정 → Rutz's Discord Table*, 도구는 왼쪽 **러츠 툴킷** 탭에 있습니다.
PF2e에서 Rutz's PF2e HUD를 함께 켜면 이 모듈은 쉬고 HUD가 같은 기능을 맡습니다.
